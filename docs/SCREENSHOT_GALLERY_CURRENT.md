### Refresh captures after future visual changes

Run the current screenshot script in the web directory once the development server is running on port 4173:

```bash
cd web
npm ci
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 4173
# In a second terminal:
PP_BASE_URL=http://127.0.0.1:4173 node scripts/capture-current-docs.mjs
```

The script writes images and a manifest to `docs/screenshots/current/`. Do **not** hand-edit captures or substitute invented values. The CI capture workflow can refresh the same files automatically after an approved documentation update.
